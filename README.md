# Alpha Academy (AlphaAcademy)

> **"Learn Simply. Prepare Smartly. Succeed Confidently."**

A premium, modern, highly animated educational platform for **Alpha Academy**, founded in 2023 by **Sabarna Suresh**, specialising in **UGC NET – English Literature** preparation.

---

## 🌟 Brand & Academy Overview

- **Brand:** Alpha Academy
- **Founder & CEO:** Sabarna Suresh (Educator | Academic Trainer | Mentor)
- **Founded:** 2023
- **Specialisation:** UGC NET – English Literature
- **Core Mission:** Making exam preparation simpler, smarter, and more effective through conceptual clarity and exam-tested study resources.

---

## 🚀 Key Features

1. **Hero Section:** Animated typography, interactive academic composition, trust indicators, and official Alpha Academy emblem.
2. **About Section:** Narrative on founding vision and interactive statistics counters (2023 Founded, 5+ Years Experience, 7 Published Study Materials, 100% Specialisation).
3. **Founder Profile:** Sabarna Suresh's background, repeated UGC NET qualification credentials, 4-pillar methodology, and milestone timeline.
4. **Core Philosophy:** Interactive "What We Believe" quote deck with smooth scroll reveals.
5. **Vision & Mission:** Comprehensive vision statement and 10 interactive mission cards.
6. **Why Alpha Academy:** 6 interactive feature cards with 3D tilt, gold glow borders, and active highlights.
7. **Study Materials Catalog:** 7 published reference volumes with 3D cover interactions, category filtering, detailed modal preview, and enquiry triggers.
8. **Student & Material Reviews:** Dedicated carousels for study material feedback and candidate testimonials.
9. **Class Details:** Structured batch cards (Online / Offline / Hybrid), curriculum module breakdowns, mock tests, and PYQ analysis info.
10. **Learning Journey:** 5-step interactive roadmap (*Understand → Learn → Practice → Revise → Succeed*).
11. **Subjects & Learning Areas:** Interactive disciplinary explorer covering Literary Theory, British Canons, Movements, Cultural Studies, and Exam Strategy.
12. **FAQ Section:** 11-question interactive accordion with category filters.
13. **Social Media & Community Hub:** Direct links and follower highlights for Instagram (`@tnalphaacademy`), YouTube, and Facebook.
14. **Interactive Contact & Enrolment:** Validated enquiry form with confetti feedback and direct advisory channels.

---

## 🛠️ Technology Stack

- **Framework:** React 19 + TypeScript + Vite 8
- **Styling:** Tailwind CSS v4 + Custom Design Tokens
- **Animations:** Framer Motion
- **Icons:** Lucide React + Custom SVG Icons
- **Effects:** Canvas Confetti

---

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/sivakumarelango10-art/alphaacademy.git

# Navigate to project directory
cd alphaacademy

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
